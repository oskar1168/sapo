Sapo 작업 리뷰

작성일: 2026-06-19 / 대상: 추천 탐색, 예약, 쇼핑 쿠폰, 일정 생성 UX, Supabase 최적화 후속

요약

오늘 작업은 앱의 첫 진입 흐름과 수익화 동선을 더 자연스럽게 정리하고, 일정 생성에서 사용자가 추천 일정과 빈 일정을 직접 선택할 수 있게 만든 것이 핵심입니다. 추천 지역 탐색은 더 조밀하게 볼 수 있도록 조정했고, 예약/쿠폰/맛집 카테고리를 보강했습니다.

주요 변경

1. 첫 일정 생성 UX 개선

  • 아직 일정이 없을 때 기본 도시가 바로 노출되는 어색함을 줄이고, 도시 선택을 먼저 유도하도록 문구와 CTA를 정리했습니다.
  • 일정 생성 모달에 추천 일정으로 시작과 빈 일정으로 시작 선택지를 추가했습니다.
  • 빈 일정 선택 시 여행 기간에 맞춰 day1 ~ dayN만 생성하고 장소 목록은 비워둡니다.

2. 추천 지역 탐색과 예약 영역 정리

  • 추천 지역 카드는 화면 폭에 따라 3열 중심으로 보이도록 정리해 예약 영역까지 접근하기 쉽게 했습니다.
  • 예약 영역의 전체 탭과 더보기 흐름을 제거하고, 페이지 진입 시 카테고리 하나가 랜덤으로 선택되도록 바꿨습니다.
  • 예약 카테고리에 맛집을 추가해 마이리얼트립 검색 링크 기반의 도시별 맛집 예약 동선을 마련했습니다.

3. 쇼핑 쿠폰 연결

  • 쇼핑 탭의 쿠폰 바로가기를 모달로 전환했습니다.
  • 돈키호테, 빅카메라, 도시별 드럭스토어 쿠폰 검색 링크를 Klook 기반으로 모았습니다.
  • 도시 코드에 따라 공통 쿠폰과 지역 쿠폰이 함께 표시되도록 데이터 파일을 분리했습니다.

4. 안정성 보강

  • 스팟 아코디언 확장 상태를 배열 index가 아니라 spot key 기반으로 관리해 필터링 후 엉뚱한 카드가 열리는 문제를 줄였습니다.
  • 일정 생성/수정 모달 본문을 스크롤 가능하게 만들어 작은 안드로이드 화면에서도 선택 카드와 날짜 입력이 잘리지 않도록 보강했습니다.

검증

  • npm run lint 통과
  • npm exec tsc -- --noEmit 통과

남은 확인 포인트

  • 실제 안드로이드 APK에서 일정 생성 모달의 날짜 선택과 새 시작 방식 선택 UI를 한 번 더 확인하는 것이 좋습니다.
  • 제휴 URL은 실제 제휴 계약 후 tracking URL로 교체해야 수익 정산이 가능합니다.
  • 추천 스팟/예약 상품 썸네일은 라이선스가 명확한 소스 또는 자체 업로드 이미지 전략을 확정해야 합니다.
